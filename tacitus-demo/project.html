Local evidence inspector

tacitus-workbench

Reopen a research selection or Context export and inspect the exact passages, qualifications and omissions behind it.

Static readers, recorded local UI and opt-in native execution are separate modes. Hosted multiuser operation is unsupported.

Run the actual project

Node 24+, npm and Python 3.11+. Native execution is an additional opt-in workflow.

cd apps/workbench
npm ci --ignore-scripts
npm run typecheck
npm run build:showcase
npm run preview:showcase

These are application instructions. Check the repository guide for recorded pass/fail results before treating them as verified. The mansion is a separate synthetic teaching demo.
